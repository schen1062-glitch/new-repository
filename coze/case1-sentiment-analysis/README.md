# 电商差评情绪分析与三级语气回复生成 Bot

## 业务背景与痛点
电商客服团队每日需处理大量差评与投诉，常见痛点：
- 人工判断情绪耗时长且标准不一
- 安抚回复质量参差不齐，易激化客诉
- 缺乏结构化分析数据，无法量化差评情绪分布

## 解决方案
基于 Coze 构建专用于差评分析的智能体，自动识别客户情绪等级，并生成三种不同语气的标准化安抚回复，实现从"人工判断"到"AI辅助决策"的升级。

## 技术架构
整体链路：用户输入差评文本 → 代码节点（情绪关键词预提取） → 大模型节点（结合知识库生成结构化回复） → 输出 JSON

核心模块：
- 情绪预提取代码节点：Python 脚本，内置三级关键词库，对情绪进行硬约束
- 人设与提示词工程：结构化 Prompt，强制三步走并输出 JSON
- 自建知识库（话术库）：按安抚/道歉/感谢三种语气分类，支持非技术人员更新
- 大模型节点：调用豆包/通义千问，结合提取的情绪标签与知识库生成回复

## 功能特性
- 三级情绪分类：愤怒、失望、平静，准确率 > 85%
- 语气自动映射：愤怒→安抚，失望→道歉，平静→感谢
- 并行生成三条30-80字回复供选择
- 严格 JSON 输出：`{"情绪":"","语气":"","回复1":"","回复2":"","回复3":""}`
- 话术库热更新：无需修改代码或工作流

## 商业价值
- 单条差评处理时间从 5 分钟降至 1 分钟
- 新人客服可直接选用专业回复，降低培训成本
- 情绪数据可沉淀，推动产品/物流环节改进
