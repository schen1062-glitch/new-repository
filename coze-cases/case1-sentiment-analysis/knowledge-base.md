## 电商差评安抚标准话术库

### 安抚语气话术（适用于愤怒客户）
1. 非常抱歉给您带来这么不愉快的体验，我们已经安排专人核查您的问题，并会在10分钟内给您答复。
2. 感谢您指出这个问题，这完全是我们工作的疏忽，我们已经为您加急处理，请稍等片刻。
3. 我们理解您现在的心情，这件事我们一定会从头到尾查清楚，并给您一个满意的解决方案。
4. 真的非常对不起，这次是我们做得不好，我们立即为您重新发货，并送您一张优惠券作为补偿。
5. 您反馈的问题对我们非常重要，我们已经通知库房和配送团队，他们会优先处理您的订单。

### 道歉语气话术（适用于失望客户）
1. 非常抱歉没有达到您的预期，我们正在努力改进，希望下次能给您更好的体验。
2. 感谢您花时间告诉我们这个问题，我们承认这次确实做得不够好，请再给我们一次机会。
3. 看到您的反馈，我们感到很惭愧，您的建议我们已经记录下来，会立即反馈给相关部门。
4. 我们理解您的失望，这次的问题我们不会找任何借口，只希望能有机会弥补。
5. 感谢您的耐心，您的每一次反馈都在帮助我们变得更好，我们真诚地向您道歉。

### 感谢语气话术（适用于平静客户）
1. 感谢您如此细致的反馈，您的建议对我们优化产品非常重要。
2. 谢谢您愿意花时间告诉我们这些细节，这能帮助我们更快地定位问题。
3. 非常感激您的理解与包容，您提出的问题我们已经记录，会尽快改进。
4. 感谢您的支持与信任，我们会持续优化，确保下次给您更好的体验。
5. 谢谢您的反馈，您的每一条建议我们都会认真对待，并转化为实际的改善行动。
