# 电商合同风险审查助手

## 业务背景与痛点
电商平台商家入驻时需签署大量协议，常见风险：
- 合同中隐藏不公平条款（无限期冻结资金、单方修改权、强制独家经营等）
- 中小商家缺乏法律知识，无法自主识别
- 人工律师审查成本高（500-2000元/次）且周期长

## 解决方案
基于 Coze 构建合同风险审查智能体，自动将合同拆分为单条条款，逐条与标准条款库和风险特征库比对，输出高/中/低风险等级及具体修改建议，实现自助式审查。

## 技术架构
整体链路：用户粘贴合同文本 → 代码节点（正则拆分条款） → 大模型节点（调用双知识库审查） → 输出结构化审查报告

核心模块：
- 条款拆分代码节点：Python 正则按"第X条"拆分，解决长文本审查痛点
- 自建标准合同条款库：电商行业标准条款（结算、保证金、违约、独家经营等）
- 高风险条款特征库：7类不公平条款特征及示例，教会 AI 识别模式
- 人设与提示词工程：定义法务专家角色，强制输出六要素审查报告
- 大模型节点：同时检索双知识库，逐条比对生成报告

## 功能特性
- 自动拆分条款，准确率 > 95%
- 三级风险判定：🔴高风险 / 🟡中风险 / 🟢低风险
- 每条审查包含：原条款、风险等级、问题描述、参考标准、修改建议、协商要点
- 双知识库联动：标准库提供基准，风险库提供反例
- 修改建议可直接用于商务谈判

## 商业价值
- 单次审查成本接近零（对比律师500-2000元）
- 审查时间从 2-3 天缩短至 1 分钟
- 高风险条款识别率 > 90%
- 可作为平台增值服务提升合规形象
