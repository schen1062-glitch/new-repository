ngrok 地址变更问题专项标注（常规通用办法）
核心问题：免费 ngrok 每次重启/电脑重启地址都会变化，导致外部系统（飞书、企业微信、客户配置）需要频繁更新。
推荐常规通用解决方案（国内外客户均适用，无需特殊工具）：

最佳短期方案（推荐现在用）：
固定 ngrok subdomain（免费版支持）
注册 ngrok 账号（免费）
使用命令：ngrok http --host-header=rewrite --subdomain=yourname 5678
地址变为 https://yourname.ngrok-free.dev（固定不变）

中长期推荐（商用交付首选）：
Cloudflare Tunnel（免费固定域名，已尝试但需稳定 Token）
本地 VPS / 轻量服务器（阿里云/腾讯云/Oracle Free Tier，月费低，固定 IP + 域名）
n8n Cloud（官方，$20+/月，零维护，Production URL 永久稳定）
Pinggy / LocalXpose 等 ngrok 替代品（部分支持固定域名）


在 .env 和工作流中的最佳实践（已在交付包标注）：

始终通过环境变量 WEBHOOK_URL 和 N8N_HOST 统一管理
每次地址变更后，只需改 .env → docker compose restart n8n
客户交付时建议他们使用 n8n Cloud 或自有域名
